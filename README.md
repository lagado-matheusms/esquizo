# Usando C# no Godot
Para usar o C# no Godot, é recomendável ter o Visual Studio Code (ou outro IDE que processe código em C#) instalado. O IDE nativo do Godot é inferior a outros que existem de forma pública, principalmente pelos seus visuais e velocidade de processamento. Na versão 4.7.2, é possível realizar a integração ao acessar `Editor > Editor Settings > Dotnet > Editor`. Defina `External Editor` como `Visual Studio Code and VSCodium`, e defina `Custom Exec Path` como o caminho para o arquivo lnk do VSCode no seu computador.
Como as convenções de nomeação do C# e da GDScript variam, é comum encontrar cenários onde a cammelCase é substituída pela PascalCase, e vice-versa.
